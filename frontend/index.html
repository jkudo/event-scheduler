配置アルゴリズム説明

自動配置ボタンを押した際に実行されるスタッフ配置アルゴリズムの仕組みを説明します。

全体フロー

1. 既存配置クリア → 2. セッション順にループ → 3. スタッフをスコアリング → 4. 上位から配置 → 5. 初心者制約の調整

ロールによるフィルタリング

セッションのカテゴリに応じて、対応するロールのスタッフのみが候補になります。

セッションカテゴリ対象スタッフロール
一般 / 技術 / WS / 基調講演 / LTセッション
受付受付
懇親会懇親会

配置前の必須チェック

  • 活動可能時間: スタッフの活動可能時間帯にセッション全体が収まること（未設定の場合は制約なし）
  • 時間重複: 既に配置済みの別セッションと時間が重複しないこと
  • 最大稼働時間: スタッフの合計稼働時間が上限を超えないこと
  • 最低配置人数: 各セッションに最低2名を配置（設定値が2未満の場合でも2名）

スコアリング（優先度の計算）

各スタッフに対してスコアを計算し、スコアが高い順に配置します。

項目スコア説明
希望セッション最大 +100優先度1 = +100, 優先度2 = +80, 優先度3 = +60 ...
英語対応+50英語対応が必要なセッションで、英語OKスタッフの場合
担当件数均等化-5 / 件既に担当しているセッション数に応じて減点（負荷分散）
階移動ペナルティ-3 / 階直前セッションの部屋と階が異なる場合、階差分だけ減点

初心者制約（2段階）

第1段階: 配置時の優先確保

  • 未経験の初心者（経験回数=0）が候補にいる場合、まず経験者を1名優先的に配置
  • その後、残り枠を通常のスコア順で埋める

第2段階: 配置後のスワップ調整

  • 全セッションの配置完了後、初心者のみで構成されたセッションがないかチェック
  • 該当がある場合、同時間帯の別セッションに配置された経験者とスワップ（入れ替え）
  • スワップ先のセッションに経験者が残ることを保証（経験者が1人しかいない場合はスワップしない）

※ 一度経験者と組んでセッションを担当した初心者は「訓練済み」として、以降は経験者扱いになります。

必要スタッフ数の自動計算

「セッション管理」タブの「必要スタッフ数を自動計算」ボタンで実行されるロジックです。

指標計算方法
セッション別必要人数 活動可能スタッフ数 ÷ 同時開催セッション数（最低2名、最大3名）
最小必要人数 全時間帯で「稼働中セッションの必要人数合計」の最大値
休憩込み必要人数 上記に加え、直前30分以内に終了したセッション担当者（休憩中）も加算した最大値

手動配置の制約

  • プルダウンには時間が重複しないスタッフのみ表示されます
  • バックエンドでも時間重複を二重チェックし、重複があればエラーメッセージで通知します
  • 同一スタッフを同一セッションに重複配置することはできません
