配置アルゴリズム説明

自動配置ボタンを押した際に実行されるスタッフ配置アルゴリズムの仕組みを説明します。

全体フロー

1. 既存配置クリア → 2. セッション順にループ → 3. スタッフをスコアリング → 4. 上位から配置 → 5. 初心者制約の調整

ロールによるフィルタリング

セッションのカテゴリに応じて、対応するロールのスタッフのみが候補になります。

セッションカテゴリ対象スタッフロール
一般 / 技術 / WS / 基調講演 / LTセッション
受付案内受付案内
懇親会懇親会

配置前の必須チェック

  • 活動可能時間: スタッフの活動可能時間帯にセッション全体が収まること（未設定の場合は制約なし）
  • 時間重複: 既に配置済みの別セッションと時間が重複しないこと
  • 最大稼働時間: スタッフの合計稼働時間が上限を超えないこと
  • 最低配置人数: 各セッションに最低2名を配置（設定値が2未満の場合でも2名）

スコアリング（優先度の計算）

各スタッフに対してスコアを計算し、スコアが高い順に配置します。

項目スコア説明
希望セッション最大 +100優先度1 = +100, 優先度2 = +80, 優先度3 = +60 ...
英語対応+50英語対応が必要なセッションで、英語OKスタッフの場合
担当件数均等化-5 / 件既に担当しているセッション数に応じて減点（負荷分散）
階移動ペナルティ-3 / 階直前セッションの部屋と階が異なる場合、階差分だけ減点

初心者制約（2段階）

第1段階: 配置時の優先確保

  • 未経験の初心者（経験回数=0）が候補にいる場合、まず経験者を1名優先的に配置
  • その後、残り枠を通常のスコア順で埋める

第2段階: 配置後のスワップ調整

  • 全セッションの配置完了後、初心者のみで構成されたセッションがないかチェック
  • 該当がある場合、同時間帯の別セッションに配置された経験者とスワップ（入れ替え）
  • スワップ先のセッションに経験者が残ることを保証（経験者が1人しかいない場合はスワップしない）

※ 一度経験者と組んでセッションを担当した初心者は「訓練済み」として、以降は経験者扱いになります。

必要スタッフ数の自動計算

「セッション管理」タブの「必要スタッフ数を自動計算」ボタンで実行されるロジックです。

指標計算方法
セッション別必要人数 活動可能スタッフ数 ÷ 同時開催セッション数（最低2名、最大3名）
最小必要人数 全時間帯で「稼働中セッションの必要人数合計」の最大値
休憩込み必要人数 上記に加え、直前30分以内に終了したセッション担当者（休憩中）も加算した最大値

手動配置の制約

  • プルダウンには時間が重複しないスタッフのみ表示されます
  • バックエンドでも時間重複を二重チェックし、重複があればエラーメッセージで通知します
  • 同一スタッフを同一セッションに重複配置することはできません

利用方法

Conference Scheduler とは

カンファレンスやイベントの運営に必要な、部屋・セッション・スタッフの管理と配置を一元的に行えるツールです。データはすべてサーバー上に保存され、複数人で同時にアクセスできます。

推奨ワークフロー

1
部屋管理で会場の部屋を登録（名前・定員・階数）
2
会場地図で会場のフロアマップを登録（参加者の案内用）
3
セッション管理でセッションを登録（タイトル・登壇者・時間・部屋・カテゴリ）。LTセッションは登壇者を個別追加可能
4
スタッフ管理でスタッフを登録（スキル・英語対応・稼働可能時間・希望セッション）
5
配置表タブで自動配置を実行。セッションクリックで手動調整も可能
6
セッション担当・受付案内担当・懇親会担当で当日運営に必要な情報を確認・印刷

各タブの機能

タブ名 説明
部屋管理 会場の部屋を登録・編集・削除。名前、定員（人数）、階数を設定できます。
全体スケジュール 全部屋のタイムテーブルを一覧表示。全体のスケジュール確認や印刷に使用します。
会場地図 会場のフロアマップ画像を登録。受付案内の印刷物に含まれます。
セッション管理 セッションの登録・編集。カテゴリ（一般/LT/基調講演/全体）、登壇者情報（写真・所属・肩書）、必要スタッフ数、英語セッションフラグを設定。「必要スタッフ計算」ボタンで定員ベースの推奨値を算出できます。
スタッフ管理 運営スタッフの登録。スキル（音響/配信/受付案内等）、英語対応可否、最大稼働時間、経験回数、対応可能時間帯、希望セッションを設定できます。
配置表 スタッフ配置の一覧をマトリクス形式で表示。自動配置の実行、セッションクリックで手動配置の追加・削除、ドラッグ&ドロップでのセッション移動が可能です。
受付案内担当 受付案内スタッフ向けの配置シート。セッション一覧・会場地図・受付案内担当者の情報をまとめて印刷できます。
懇親会担当 懇親会セッションに配置されたスタッフの一覧と担当詳細を表示します。
配置アルゴリズム スタッフの自動配置を実行。スキルマッチ・英語対応・稼働時間・希望を考慮して最適配置を算出します。結果はプレビュー後に適用できます。
エクスポート/インポート Excel出力（スケジュール表・スタッフ配置表）、バックアップ（ZIP形式で全データ保存・復元）、connpass用のMarkdown出力（タイムライン・登壇者テンプレート）に対応。
設定 全データの初期化（パスワード必要）。バックアップを取ってから実行してください。

セッションカテゴリについて

general（一般）

通常の講演セッション

keynote（基調講演）

基調講演・メインセッション

lt（LT）

ライトニングトーク。複数登壇者を個別登録可能

overall（全体）

休憩・懇親会等。connpass出力では除外されます

Tips

  • セッション一覧・配置表でセッション名をクリックすると詳細ポップアップが表示されます
  • スタッフ写真をクリックすると拡大表示されます
  • 受付案内担当タブは印刷に最適化されています（ブラウザの印刷機能を使用）
  • バックアップZIPにはすべてのデータと画像が含まれます。定期的にエクスポートすることを推奨します
  • connpass出力ではBase URLを設定すると、登壇者写真のURLが自動生成されます
  • 配置アルゴリズムは何度でも実行可能です。プレビューで確認してから適用してください
